🎓 How Ninja's Identify API Works Behind The Scenes

REST API
When the user clicks submit, ApexBet calls Ninja server-side using verify mode. Ninja queries the central database and calculates a match confidence score while validating the date of birth.
HTTP Request Payload to Ninja: 
POST /api/identity/identify HTTP/1.1
Host: api.sandbox.ninja.boucloud.io
Authorization: Bearer sk_live_...
Content-Type: application/json

{
  "idType": "bvn",
